# あいのて

不動産仲介の仕事を、手元のMacでまとめて進めるオープンソースの業務支援ソフトです。

物件、顧客、タスク、重要事項説明書、マイソクを一つの画面で管理できます。
業務データは利用者のMacに保存し、初期状態では外部へ送信しません。

[最新版をダウンロード](../../releases/latest)

## できること

- 今日やる仕事を一覧で確認する
- 物件、顧客、問い合わせをまとめて管理する
- 重要事項説明書とマイソクの下書きを作る
- Word、Excel、印刷用PDFとして書き出す
- 変更履歴を確認し、以前の状態へ戻す
- 暗号化バックアップを作る

承認、記名確定、保留解除、外部送信は、利用者が画面で確認して実行します。

## はじめる

### 1. 動作環境を確認する

Apple Silicon搭載MacとPython 3.12以上が必要です。

```bash
python3 --version
```

Pythonが入っていない場合は、[Python公式サイト](https://www.python.org/downloads/)からインストールしてください。

### 2. ダウンロードしたZIPを展開する

展開した`ainote-local-web`フォルダをターミナルで開き、次の2行を実行します。

```bash
python3 install_ainote.py --venv .venv
.venv/bin/python start_ainote.py
```

ブラウザが自動で開きます。
開かない場合は、[http://127.0.0.1:8788/](http://127.0.0.1:8788/)を開いてください。

終了するときは、ターミナルで`Control + C`を押します。

### 3. 初回設定を行う

画面に沿って、次の3項目を設定します。

1. 会社情報
2. ログインIDとパスワード
3. AIの利用方法

AIは「使わない」を選んだままでも始められます。

## データとAI

通常のデータ保存先は`~/ainote-data/out`です。

AIは次の3つから選べます。

- AIを使わない
- Mac内のOllamaを使う
- 自分で用意したAnthropic APIキーを使う

外部AIや外部サービスは、利用者が設定した場合だけ接続します。
あいのては法的判断や宅地建物取引士本人の確認を代行しません。

## 対応環境

- 公式サポート：Apple Silicon搭載Mac
- 検証済み：macOS 26.4および26.6.2、Python 3.14
- 必要なPython：3.12以上
- Windows：現在は公式サポート対象外
